## 🚀 Featured Projects

### ☸️ [GitOps Task Manager](https://github.com/shravanmungarwadi/GitOps-Task-Manager)
Full-stack app (React + Node.js + PostgreSQL) deployed on **AWS EKS** with a fully automated GitOps flow.
- **Terraform** provisions VPC + EKS, with remote state in S3 + DynamoDB
- **GitHub Actions** runs tests → **Trivy** image scan → build → push → Helm tag bump
- **ArgoCD** auto-syncs Helm charts to the cluster; Nginx Ingress behind an AWS ELB
- **Prometheus + Grafana** dashboards; one-command deploy via `scripts/deploy.sh`

`AWS EKS` `Terraform` `Helm` `ArgoCD` `GitHub Actions` `Trivy` `Prometheus` `Grafana`

### 🐳 [Full-Stack Deployment on AWS EC2](https://github.com/shravanmungarwadi/Full-Stack-Deployment)
Django REST + React (Vite/TypeScript) app, containerized and deployed to EC2.
- Multi-stage Docker builds running as a non-root user; Nginx reverse proxy
- CI/CD pipeline: lint → test → build → deploy with GitHub Actions
- Terraform for EC2, VPC, security groups, Elastic IP, S3, and IAM role
- Prometheus, Grafana, and Node Exporter monitoring

`AWS EC2` `Docker` `Terraform` `GitHub Actions` `Nginx` `Prometheus`

### 🔐 [DevSecOps Microservices Pipeline](https://github.com/shravanmungarwadi/DevSecOps-Microservices-Pipeline) — 🚧 *In progress*
Spring Boot microservices (product, order, payment) being taken through a security-focused CI/CD pipeline.
